# Teretana

Web aplikacija za upravljanje teretanom i rezervaciju termina treninga, napravljena u PHP-u i MySQL-u.

## Uloge i funkcionalnosti

**Clan:**
- pregled liste termina i detalja termina
- rezervacija termina
- pregled i otkazivanje svojih rezervacija

**Trener:**
- pregled svojih termina
- kreiranje i izmena termina treninga
- pregled clanova prijavljenih na termin

**Administrator:**
- dashboard sa pregledom
- upravljanje korisnicima (dodavanje, izmena, brisanje, pregled)
- izvestaji

## Tehnologije

- PHP
- MySQL
- HTML, CSS
- PDO,
- Bootstrap 5,
- password_hash

## Pokretanje

1. Instaliraj XAMPP (ili slican server sa PHP-om i MySQL-om).
2. Kopiraj folder projekta u `htdocs`.
3. Napravi bazu u phpMyAdmin-u i uvezi SQL skriptu.
4. Podesi podatke za konekciju u `config/db.php`.
5. Otvori `http://localhost/teretana` u browseru.
